# Private Project Template

このリポジトリは、個人的なプロジェクトにおいてよくある構成をテンプレート化するためのものです。
このテンプレートでは、主にドキュメンテーションの構成と、 AI との協業を想定した構成を提供します。
なお、プロジェクトは日本語を前提としている点に注意してください。

このテンプレートをプロジェクトへ適用する際には、この README もプロジェクト固有の内容に置き換えられることを想定しています。

## :art: ディレクトリ構造

このリポジトリでは、大きく次のようなディレクトリ構造でソースコードと関連ファイルを管理しています。

- `docs/` ... ドキュメントとそれに関連するファイルを管理するためのディレクトリ
  - `dev-docs/` ... 開発ドキュメントを管理するためのディレクトリ
