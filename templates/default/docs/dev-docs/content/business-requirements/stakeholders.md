# ステークホルダー

## 概要

ビジネス要求のユーザーストーリーの主体 (「〜として」) となるロールを定義する。
ユーザーストーリーでは、本ドキュメントで定義したロール名を用いる。

ここで定義するのは、特定の個人像 (ペルソナ) ではなく、組織上の立場と関心 (ロール) である。1 人が複数のロールを兼ねてもよい。
