### 画像

| 用途                               | ファイル                    | プレビュー                      |
| ---------------------------------- | --------------------------- | ------------------------------- |
| ファビコン (ライト/ダーク自動切替) | `static/images/favicon.svg` | ![favicon](/images/favicon.ico) |
| リポジトリ/アバターアイコン (静的) | `static/images/logo.svg`    | ![icon](/images/logo.svg)       |

`favicon.svg` は、 `prefers-color-scheme` に応じて背景・アイコン双方の色をライト/ダークで自動的に切り替える構成としています (対応ブラウザのみ) 。
一方、 `icon.svg` は GitHub や Backlog などのアバター/アイコンとしてアップロードすることを想定し、ライトモード配色に固定した静的な1枚としています。

### 使用上の注意

- 上記のファビコン・アイコンは SVG 1つのシェイプ (単一の `polygon`) のみで構成されている。将来的にロゴタイプなど文字要素を組み合わせた表現が必要になった場合は、本アイコンをベースとして別途デザインする。
