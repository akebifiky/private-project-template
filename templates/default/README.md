# Private Project Template

このリポジトリは、個人的なプロジェクトにおいてよくある構成をテンプレート化するためのものです。
このテンプレートでは、主にドキュメンテーションの構成と、 AI との協業を想定した構成を提供します。
なお、プロジェクトは日本語を前提としている点に注意してください。

このテンプレートをプロジェクトへ適用する際には、この README もプロジェクト固有の内容に置き換えられることを想定しています。

## :art: ディレクトリ構造

このリポジトリでは、大きく次のようなディレクトリ構造でソースコードと関連ファイルを管理しています。

- `docs/` ... ドキュメントとそれに関連するファイルを管理するためのディレクトリ
  - `dev-docs/` ... 開発ドキュメントを管理するためのディレクトリ

## 置換ポイント

プロジェクトに対してこのリポジトリで管理されるプロジェクト構造のテンプレートを適用する際には、
以下のポイントについてそれぞれ適用先のプロジェクト用の記述に置換されることを想定します。

### 開発ドキュメント

- Docusaurus 設定 (`docs/dev-docs/docusaurus.config.ts`) ... プロジェクト名・アイコン画像
- UI デザイン (`docs/dev-docs/content/system-design/ui-design.md`) ... カラースキーム及びアイコン画像を含むデザインルールを作成して詳細を記載する
- コーディング規約 (`docs/dev-docs/content/project-rules/coding-styles*.md`) ... プロジェクトで利用する想定の言語に合わせて調整する
