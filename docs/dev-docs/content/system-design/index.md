# システムデザインについて

システムデザインは、システムの構造や動作を定義するドキュメント群です。
これらのドキュメントは、 [システム要件](../system-requirements/index.md) を満たすための具体的な設計を示し、実装の指針を提供することを目的としています。

開発ドキュメントは、 [ビジネス要求](../business-requirements/index.md) で「Why (なぜ) 」を、 [システム要件](../system-requirements/index.md) で「What (何を) 」を定義した後、システムデザインで「How (どのように) 」を定義する 3 層で構成されます ([ADR-0007](../adr/ADR-0007-three-layer-dev-docs.md) を参照) 。
