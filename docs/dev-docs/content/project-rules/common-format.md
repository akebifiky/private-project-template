# 共通フォーマット

以下で示される原則は、本プロジェクトに関わるドキュメント・ソースコードを含む全ての成果物に適用されるものとします。

## テキストの書式・体裁規定

### 1. 全角記号の使用禁止

以下の記号については、 **必ず半角文字を用いて記載** し、全角文字を使用してはならない。

| 名称             | 記号                     |
| ---------------- | ------------------------ |
| スペース         | 半角スペースのみ使用する |
| 括弧             | `()`, `[]`, `{}`         |
| ハイフン         | `-`                      |
| プラス           | `+`                      |
| アットマーク     | `@`                      |
| ナンバー         | `#`                      |
| ドル             | `$`                      |
| パーセント       | `%`                      |
| キャレット       | `^`                      |
| アンパサンド     | `&`                      |
| アスタリスク     | `*`                      |
| アンダースコア   | `_`                      |
| イコール         | `=`                      |
| 不等号           | `<`, `>`                 |
| クォート         | `'`, `"`                 |
| カンマ           | `,`                      |
| ピリオド         | `.`                      |
| コロン           | `:`                      |
| セミコロン       | `;`                      |
| スラッシュ       | `/`                      |
| バックスラッシュ | `\`                      |
| パイプ           | `\|`                     |

#### 例外

次の記号については、**全角文字を用いて記載** すること。

| 名称     | 記号           |
| -------- | -------------- |
| カギ括弧 | `「」`, `『』` |

**備考**

上記で規定されない記号については、前後の文脈 (日本語/英語) に応じて自然な形を採用するものとする。

例:

- 日本語文：`危ない！` (全角)
- 英語文：`CAUTION!` (半角)

### 2. 全角英数字の禁止

- 英数字は **すべて半角** で記載すること。
- 全角英数字は、入力フォームの制限など特別な理由がある場合を除き、使用してはならない。

### 3. 和英混在文のスペース規則

日本語の全角文字と英字などの半角文字が混在する場合、 **半角文字の前後に半角スペースを1つ設ける** こと。

例:

- ✅ 正: `こちらの URL をクリックしてください。`
- ❌ 誤: `こちらのURLをクリックしてください。`

#### 例外

| 記号                    | 書式ルール                                                                                             |
| ----------------------- | ------------------------------------------------------------------------------------------------------ |
| 括弧 (`()`, `[]`, `{}`) | 内側にスペースを設けない (例：`テキスト (補足)`)                                                       |
| クォート (`'`, `"`)     | 内側にスペースを設けない (例：`"テキスト"`)                                                            |
| コロン (`:`)            | 言葉の定義や説明を示す場合は、前にスペースを設けない (例：`言葉の定義: その説明`)                      |
| 物量を示す数値          | 単位を伴う数値は、数字との間にスペースを設けなくてもよい (例： `リンゴを2個買う`, `容量100MBを要する`) |

## Markdown の記法

### 1. Admonition (注記・警告)

Markdown 内で注記や警告などの Admonition を記載する場合は、 Git サービス (GitHub/GitLab など) 上でも Admonition として表示されるよう、 **原則として引用ブロックを用いた GitHub スタイルの記法を用いる** こと ([ADR-0004](../adr/ADR-0004-support-github-style-admonitions.md)) 。

```markdown
> [!NOTE]
> ざっと読む場合でも知っておいてほしい情報。

> [!TIP]
> より良く、より簡単に作業するための助言。

> [!IMPORTANT]
> 目的を達成するために知っておく必要がある重要な情報。

> [!WARNING]
> 問題を避けるために直ちに注意を払うべき情報。

> [!CAUTION]
> 特定の操作によるリスクや悪影響についての注意。
```

開発ドキュメント (Docusaurus) 上では、上記の記法は Docusaurus 標準の Admonition へ変換されて表示される。

| GitHub スタイル | Docusaurus 上での表示 |
| --------------- | --------------------- |
| `[!NOTE]`       | `note`                |
| `[!TIP]`        | `tip`                 |
| `[!IMPORTANT]`  | `info`                |
| `[!WARNING]`    | `warning`             |
| `[!CAUTION]`    | `danger`              |

#### 例外

GitHub スタイルの記法ではタイトルを指定できないため、タイトルの指定が必要な場合に限り、 Docusaurus のディレクティブ構文 (例: `:::note[タイトル]`) を用いてもよい。
